# SAVVA · ساڤا — демо-сайт кофейни

Демоверсия сайта спешелти-кофейни SAVVA (Медина, Саудовская Аравия).
Только фронтенд, без бэкенда. Все кнопки работают в пределах браузера.

## Запуск

```
npm install
npm run dev      # http://localhost:4322
npm run build    # статика в dist/
```

## Что внутри

- **Меню** — 40 позиций из официального PDF заведения, цены в риалах, калорийность.
- **Арабский и английский** с настоящим RTL, переключатель в шапке.
- **Корзина, заказ, бронь стола** — работают, состояние в localStorage, наружу
  ничего не уходит. Экран подтверждения помечен как демо.
- **Галерея** — 9 снимков из @savva_cafe.
- **Карта, часы, контакты** — с карточки Google.

## Файлы данных

| Файл | Что |
|---|---|
| `src/data/menu.ts` | все позиции, цены, калории, опции напитков |
| `src/data/venue.ts` | адрес, часы, телефон, ссылки |
| `src/data/booking.ts` | демонстрационная занятость столов |
| `src/data/photos.ts` | галерея, каждый снимок с источником |
| `src/lib/submit.ts` | единственная точка подключения бэкенда |
| `src/i18n/index.ts` | все строки интерфейса на двух языках |

## Перед боевым запуском

См. `ЗАМЕНИТЬ.md` — опечатки в меню, часы открытия, опции напитков,
разрешение фотографий, точка на карте.

## Стек

Astro 5, Tailwind 4, разворачивается на Cloudflare Pages.
Бренд-графика (логотип, ветка, тень листвы, символ риала) извлечена
векторами и масками из PDF-меню заведения, лежит в `public/brand/`.
